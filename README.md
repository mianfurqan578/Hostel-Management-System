# 🏨 Hostel Management System

> A modern web-based system designed to simplify and organize hostel management operations.

## 📌 Overview

The **Hostel Management System** is a full-stack web application developed to manage essential hostel activities through a centralized platform.

It allows administrators to manage students, rooms, room allotments, and fee records while providing a simple dashboard for monitoring hostel information.

## ✨ Key Features

- 🔐 Secure Admin Login
- 👨‍🎓 Student Management
- 🏠 Room Management
- 🛏️ Room Allotment
- 💰 Fee Management
- 📊 Admin Dashboard
- ✏️ Update Student Records
- 🗑️ Delete Records
- 💵 Paid / Unpaid Fee Tracking
- 📈 Hostel Occupancy Overview

## 🧰 Tech Stack

| Layer | Technologies |
|------|-------------|
| Frontend | HTML5, CSS3, Bootstrap |
| Backend | Python, Flask, Jinja2 |
| Database | MySQL, SQL |
